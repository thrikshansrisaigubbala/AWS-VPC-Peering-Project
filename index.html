Project Overview

This project demonstrates how to create and configure two Amazon Virtual Private Clouds (VPCs) using AWS. It includes public and private subnets, EC2 instances, an Internet Gateway, route tables, security groups, and VPC peering.

The purpose is to demonstrate private IP communication between EC2 instances located in different subnets and different VPCs.

Project Conclusion

The project demonstrates VPC creation, subnet configuration, Internet Gateway routing, VPC peering, route-table configuration, and connectivity testing between EC2 instances.

Both reported ping tests succeeded with zero packet loss. The project illustrates how VPC peering can enable private IP communication between separate VPCs when routes and security rules are configured correctly.
